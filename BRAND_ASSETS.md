# Finwise Brand Assets

The owner-supplied files in `finwise-brand-assets.zip` are the sole authoritative Finwise logo and icon assets. They are used without redrawing, tracing, crop edits, recolouring, added effects, alternate typography, or proportional changes. The previously recreated SVG logo variants are not used by the application.

| Supplied filename | Authoritative role | Product placement |
|---|---|---|
| `finwise-logo-dark.png.png` | Primary no-divider gold Finwise logo on deep navy | Dark application backgrounds, including the auth and workspace lockups. |
| `finwise-logo-light.png.png` | Finwise logo prepared for light backgrounds | Light theme lockups only. |
| `finwise-mark.png.png` | Standalone gold angular F mark | Symbol-only placements. |
| `favicon.png.png` | Favicon asset based on the F mark | Browser-favicon source. |
| `app-icon-192.png.png` | 192px F-mark application icon | Web-application icon variant. |
| `app-icon-512.png.png` | 512px F-mark application icon | High-resolution application icon variant. |
| `finwise-logo.png.png` | Supplied alternate full Finwise lockup | Retained as an owner-provided brand asset; not substituted for the designated dark or light UI variants. |

The supplied PNGs include their own visual treatment and intended backgrounds. The application selects the appropriate supplied light or dark image instead of modifying the logo artwork.

## Presentation Compatibility

The supplied `finwise-logo-dark.png.png` is an opaque PNG. Its sampled edge color is **`#010817`**, and the dark application canvas uses that exact value so the original logo background visually integrates with the authentication surface. No owner-supplied PNG has been cropped, traced, recoloured, or otherwise modified.
